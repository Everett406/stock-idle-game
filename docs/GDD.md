## 1. 概述

### 1.1 一句话简介

市场 24 小时持续模拟运行的真实感股票市场，玩家每次只玩 1-10 分钟：看行情、买卖、收分红、做升级，然后关掉。离线时持仓继续产生分红，回来一次性结算。

### 1.2 设计支柱

1. **碎片化优先**：任何一次会话（哪怕 60 秒）都应有可感知的收获（一笔交易/一笔分红/一次升级）。
2. **动画即灵魂**：所有数字变化必须有动画；高频小反馈轻量做，低频大事件重金做。
3. **真实感的市场**：几何布朗运动 + 均值回归 + 随机事件，走势像真的，但无需真实数据。
4. **零负担**：不盯盘、不焦虑、没有失败惩罚，关掉游戏世界继续转。

### 1.3 玩法循环

```
打开游戏 → 收离线分红（情绪高潮）→ 看行情/新闻 → 买卖调仓 → 领任务奖励
   ↑                                                      ↓
关闭游戏 ← 升级/转生 ← 总资产增长 ← 持仓持续分红（离线也在涨）←┘
```

## 2. 市场模拟系统

### 2.1 价格模型（几何布朗运动）

每只股票每秒演化一次（dt ≈ 1 秒）：

```
S(t+dt) = S(t) · exp( (μ_eff − σ²/2)·dt + σ·√dt·Z )      Z ~ N(0,1)

μ_eff = μ + E(t) − k·ln( S(t) / B )
```

| 符号 | 含义 | 取值 |
|------|------|------|
| μ | 基础漂移率（牛/熊性格） | 每股固定，见参数表 |
| σ | 波动率 | 每股固定；波动翻倍时段 ×2 |
| E(t) | 事件期额外漂移 | `ln(1±m)/T`，见 2.3 |
| k | 均值回归强度 | **2.5e-5**（全局常量） |
| B | 锚定价（初始价） | 每股固定 |

**均值回归的作用**：防止价格在长期模拟中失控（涨到天文数字或归零）。价格远离锚定价 B 时产生反向拉力。价格下限为 `max(0.05·B, ¥0.01)`。

### 2.3 随机事件系统

调度规则：
- 无事件时，每隔 `60 ~ 180 秒` 安排一次事件；
- 利好概率 **55%**（轻微正向偏置，长期市场向上）；
- 目标股票：80% 从已解锁股票中随机选，20% 从全部 12 只中选（制造"想解锁的欲望"）；
- 首次事件在开局 **25 秒** 后触发（教学期尽快展示新闻系统）。

事件参数：
```
强度 m ∈ [3%, 18%]（均匀随机）
持续时间 T ∈ [40s, 150s]（均匀随机）
事件期额外漂移：E(t) = ln(1+m)/T   （利好）或  −ln(1+m)/T   （利空）
```

事件只在持续期内推高/压低价格，结束后自然回归（无硬性价格回弹，靠均值回归收敛）。

新闻模板（占位符 `%S` 替换为股票名）：

| 利好 | 利空 |
|------|------|
| %S发布重磅新品，市场热议 | %S遭监管问询 |
| %S斩获大额订单 | %S核心高管突然离职 |
| 机构集体上调%S评级 | %S业绩暴雷，机构出逃 |
| %S业绩大超预期 | 行业寒潮：%S板块承压 |
| 政策东风：%S所在板块迎风口 | %S大股东计划减持 |
| %S核心技术取得突破 | %S主力工厂意外停产 |

事件触发时：红色 BREAKING 横幅弹入 + 震动 + 新闻音效；卡片右上角显示利好/利空角标。

### 2.4 波动翻倍时段（限时事件）

每天两个时段，全市场 σ ×2：

```
12:00 - 13:00　　20:00 - 21:00（本地时区）
```

界面在时段内显示"⏱ 波动翻倍中"角标，成长页显示下一次开启倒计时。

## 3. 交易系统

### 3.1 买卖规则

- 按金额比例下单：25% / 50% / 75% / 全仓（现金或持仓的比例）；
- 允许**碎股**（小数份额），贴合放置类游戏的顺滑数值成长；
- 无滑点、无涨停限制（单机休闲定位）。

**买入**：
```
预算 gross = 现金 × 比例
手续费 fee = gross × feeRate
股数 qty = (gross − fee) / 价格
现金 -= gross
持仓成本 += gross        ← 成本含手续费，盈亏计算更诚实
```

**卖出**：
```
卖出股数 qty = 持股 × 比例
卖出总额 gross = qty × 价格
手续费 fee = gross × feeRate
到账 net = gross − fee
已实现盈亏 += net − 成本 × (qty/持股)
现金 += net
```

**手续费率**（VIP通道升级）：
```
feeRate = max( 0.01% , 0.1% × 0.8^等级 )
```
| VIP等级 | 0 | 1 | 2 | 3 | 5 | 10 |
|---------|-----|-----|-----|-----|-----|-----|
| 费率 | 0.100% | 0.080% | 0.064% | 0.051% | 0.033% | 0.013% |

### 3.2 盈亏口径

- **浮动盈亏** = 持股市值 − 持仓成本（含手续费）
- **今日盈亏** = 当前总资产 − 日初总资产快照（跨天 00:00 重置快照）
- **已实现盈亏**：卖出时结算，累计展示

## 4. 分红系统（放置核心）

### 4.1 每秒分红

```
每秒分红 = 持股数 × 现价 × 该股每秒分红率 × 分红倍率 M

M = (1 + 0.12 × 红利基金等级) × (1 + 0.30 × 经理等级)
```

分红进入"待领取池"，玩家点【收取】入账（触发金币雨 + 飘字）。这是"每次上线都有可点的东西"的核心反馈循环。

### 4.2 离线收益

```
离线时长 = min( 本次离线秒数 , 8 小时 = 28800s )
离线分红 = Σ 持股 × 存档时股价 × 每秒分红率 × M × 离线时长
```

- 离线超过 **120 秒** 才结算（避免切后台 1 分钟也弹报告）；
- 离线分红**直接入现金**，并弹出全屏收益报告（逐项数字累加动画）；
- 量化机器人不产生离线收益（在线专属，鼓励偶尔打开看一眼）。

## 5. 增量成长系统

### 5.1 升级项（5 个）

成本公式：`cost(level) = baseCost × growth^level`（一次性买断，永久生效，转生保留）

| 升级项 | 基础成本 | 成本增长 | 等级上限 | 效果 |
|--------|----------|----------|----------|------|
| 🪙 VIP通道 | ¥800 | ×1.90 | 10 | 手续费 0.1%×0.8^L，下限 0.01% |
| 📈 红利基金 | ¥2,000 | ×1.75 | 20 | 分红倍率 ×(1+0.12L) |
| 🤖 量化机器人 | ¥50,000 | ×2.10 | 10 | 每秒套利 = 持仓市值 × 0.006% × L（在线时） |
| 🛡️ 止损保险 | ¥15,000 | ×2.00 | 8 | 每秒下跌损失 × 8% × L 赔付现金 |
| 📡 内幕雷达 | ¥30,000 | ×2.40 | 5 | 事件发生前 8+6L 秒（上限 30s）预告方向 |

- 量化机器人收益直接入现金（在线时每秒结算）；
- 止损保险把持仓的实际下行波动缩小，是后期重仓高波动股的安全网；
- 内幕雷达把随机事件变成"可操作的预告"，是花哨但强力的信息优势。

### 5.2 每日任务（每天 3 个，本地 00:00 刷新）

目标按**日初总资产**动态生成（任何阶段都只需几分钟完成）：

| 任务 | 目标 | 奖励 |
|------|------|------|
| 今日盈利 | `max(¥1,500, 日初总资产 × 2.5%)`（取整为 1/1.5/2/2.5/3/5 ×10^n 的好看数字） | 盈利目标 × 0.6 |
| 完成交易 | 6 笔（买+卖各算一笔） | max(¥300, 盈利目标 × 15%) |
| 领取分红 | 3 次 | ¥800 |

进度口径：盈利任务用"当前总资产 − 日初快照"（含浮盈，完成感更强）。

### 5.3 转生系统（无限循环核心）

```
转生门槛 = ¥1,000,000 × 8^当前经理等级
Lv.0→1 需 100万 → 800万 → 6400万 → 5.12亿 → ...
```

**保留**：升级等级、自选列表、设置、每日任务进度。
**重置**：现金、持仓、待领分红、股价（重新预热 120 秒历史）、历史最高总资产（解锁进度重新走，但初始资金更高所以立刻重新解锁前期股票）。

**转生奖励**：
```
经理等级 +1
初始资金 = ¥10,000 + ¥6,000 × 新经理等级     （16000 / 22000 / 28000 ...）
分红永久加成 = ×(1 + 0.30 × 经理等级)
```

## 6. 数值节奏（校验基准）

| 时间点 | 目标体验 | 依赖数值 |
|--------|----------|----------|
| 0-10 分钟 | 完成首笔买卖，看到第一次新闻事件，第一次分红入池 | 开局 3 只蓝筹、25 秒首事件、日分红 2.4%+ |
| 1 小时 | 领到第一笔像样的分红（几十~几百元），买 1-2 级升级 | 分红倍率、任务奖励 |
| 1 天 | 解锁第 5 只股票（¥8万），体验波动翻倍时段 | 解锁阶梯、主动交易收益 ~5-15%/h |
| 1 周 | 总资产 ≥ ¥100万，触发第一次转生 | 事件偏置、复利+分红+升级曲线 |

> 调参原则：先保证"10 分钟体验"（首笔交易 + 首个事件 + 首次收取分红全部发生），
> 再校准"1 周转生"曲线。改任何一个比率前先跑一遍心算校验。

## 8. 存档设计

### 8.1 存储方式

- 本地单文件 `filesDir/save.json`（JSON，UTF-8）；
- 原子写入：先写 `save.json.tmp` 再 rename，防止写坏；
- **触发时机**：每 30 秒 / 每次交易 / 升级 / 领取 / 转生 / 退到后台 / 设置变更。

### 8.2 字段清单

```jsonc
{
  "v": 1,                    // 存档版本号，向后兼容用
  "cash": 10000.0,           // 现金
  "pending": 0.0,            // 待领取分红
  "maxAssets": 10000.0,      // 历史最高总资产（解锁判定用）
  "managerLevel": 0,         // 经理等级
  "dayKey": "2026-09-17",    // 当前日期（跨天重置任务）
  "dayBaseline": 10000.0,    // 日初总资产快照（今日盈亏基准）
  "tradesToday": 0,          // 今日交易笔数（任务进度）
  "divClaimsToday": 0,       // 今日分红领取次数（任务进度）
  "totalTrades": 0,          // 累计交易笔数
  "realized": 0.0,           // 累计已实现盈亏
  "lastSaved": 1726550000000,// 上次存档时间戳（离线收益计算）
  "themeMode": 0, "soundOn": true, "vibrateOn": true,
  "favorites": ["wsbk"],
  "upgrades": {"fee": 1, "div": 2},
  "holdings": {"wsbk": {"s": 123.4, "c": 1000.0}},   // 股数 + 成本
  "stocks": {"wsbk": {"p": 8.61, "o": 8.55, "h": [...120个历史价]}},
  "tasks": {"day": "2026-09-17", "claimed": [0, 2]}
}
```

**重进恢复流程**：读档 → 恢复现金/持仓/价格/历史 → 计算离线时长（now − lastSaved，上限 8h）→ 累加离线分红 → 弹出收益报告 → 启动每秒循环。

## 9. 技术选型与理由

**Kotlin + Jetpack Compose（原生 Android，非网页套壳）**

| 备选 | 结论 | 理由 |
|------|------|------|
| **Jetpack Compose ✅** | 采用 | 原生性能（1Hz 全局动画无压力）；Compose 动画 API 覆盖本作全部需求（Animatable/InfiniteTransition/AnimatedVisibility/Canvas）；双主题是 Compose 的看家能力；APK 约 6MB；CI 构建只需 JDK+Android SDK，最简 |
| Flutter | 备选落选 | 动画能力同样优秀，但引入额外工具链与 20MB+ 运行时；CI 配置更重 |
| Godot | 备选落选 | 对 UI/数值驱动的放置游戏是杀鸡用牛刀，导出模板体积大 |
| 网页套壳 | ❌ 明确排除 | 用户明确要求，且性能/手感不达标 |

- 市场模拟：协程 `while(isActive) { delay(1000); step() }`，仅在应用前台运行；
- 存档：`org.json`（系统内置）+ 原子写文件；
- 音效：SoundPool + 程序合成 WAV（`scripts/gen_sounds.py` 生成，无版权风险）；
- 震动：Vibrator（API 26+ 兼容，31+ 用 VibratorManager）。

## 10. 版本管理规范

- **唯一版本来源**：仓库根目录 `version.txt`（SemVer：主.次.修订）；
- `app/build.gradle.kts` 读取 `version.txt` → versionName / versionCode（游戏内"设置"里展示的就是它）；
- 发布流程：改 `version.txt` + 写 `CHANGELOG.md` → 提交 → 打 tag `v{版本}` → 推送；
- GitHub Actions 校验 **tag == version.txt**，不一致直接构建失败（保证游戏内显示、APK 版本、Release 标签三者一致）；
- 构建产物：`StockIdle-v{版本}.apk`（release 签名，密钥在 GitHub Secrets，仓库不留密钥）。

## 11. v0.2 新增系统（数值与公式）

### 11.1 涨跌停
- 基准：每日开盘价 `dayOpen`（跨天重置为当时价格）；
- 涨停价 = `dayOpen × 1.10`，跌停价 = `dayOpen × 0.90`；
- 价格演化后 clamp 到区间内；触板后 `limitState = ±1`，成交量 ×0.15（封板缩量）；
- 无事件贴板时每秒以 4%（涨停）/ 8%（跌停）概率随机开板；事件驱动贴板在事件结束次日自然打开。

### 11.2 大盘指数
- `Index = 1000 × exp( (1/n) × Σ ln(Pᵢ/Bᵢ) )`，n 为已解锁股票数，等权几何平均；
- 每秒 push 一个点，保留 720 点（约 12 分钟分时）；启动/转生后用各股分时历史重建；
- 顶栏速览 + 行情页指数卡（数值/平均涨跌/迷你分时）。

### 11.3 限价委托单
- 买单：`limit ≤ 现价` 时按现价立即成交（对玩家有利），否则挂单并冻结 `可用现金 × 比例`；
- 卖单：`limit ≥ 现价` 时立即成交，否则冻结 `可卖股数 × 比例`；
- 撮合：买单 `P ≤ limit` 成交，卖单 `P ≥ limit` 成交，成交价 = 触发时现价，手续费按成交时费率；
- 委托长期有效，可随时撤单释放冻结；成交推 `OrderFilled` 事件（音效+震动+通知）。

### 11.4 五档盘口（模拟）
- 档位价：`P × (1 ± 0.004×k + k×0.0004)`，k=1..5；
- 档位量：确定性伪随机（股票 id + 档位哈希）× 行情热度 `heat = 当前秒成交量 / 近 60 秒峰值`，量条可视化。

### 11.5 事件系统扩容
- 触发分布：个股事件 67% / 板块事件 18% / 财报事件 15%；
- 板块事件：同板块全部已解锁股受冲击，幅度在基准 ±20% 内随机化，时长各股 ±20s；
- 财报事件：`m ∈ [8%, 20%]`，时长 60-150s，好坏比 60/40。
